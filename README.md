# ✈️ Chartered Flight Database Management System (CFDBMS)

**A Database Systems Coursework Project | University of East London**

## 📌 Project Overview

The Chartered Flight Database Management System (CFDBMS) is an academic database development project based on the business requirements of Impact Charter Services (ICS), a private aviation company providing charter flight services.

The project aims to design a centralised database solution to improve the management of charter bookings, customers, aircraft, pilots, crew assignments, financial transactions and maintenance activities.

**Project Status:** 🚧 In Progress

## 🎯 Project Objectives

- Centralise customer and passenger information.
- Manage charter flight bookings.
- Maintain aircraft and pilot records.
- Organise crew assignments.
- Record financial transactions.
- Support aircraft maintenance management.
- Improve data accuracy and integrity.
- Reduce duplicate records and scheduling conflicts.

## 🏗️ Proposed System Scope

The database is intended to support the following operational areas:

1. Customer Management
2. Passenger Information
3. Charter Booking Management
4. Aircraft Management
5. Pilot and Crew Management
6. Financial Transaction Management
7. Aircraft Maintenance Management
